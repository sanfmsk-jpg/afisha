# Афиша мероприятий

Веб-приложение «Афиша мероприятий» с фильтром по датам.
Курсовой проект по МДК.09.01. Автор: Передрий Алексей Владимирович, группа 4ИСИП-1023.

## Стек

- Python 3.12, Flask 3.1 (серверная логика, маршрутизация)
- Jinja2 (шаблонизация HTML)
- SQLite 3 (хранение данных), модуль `sqlite3` + SQL-запросы
- HTML5 / CSS3 (Grid, Flexbox, media-запросы) / JavaScript (Fetch API)

## Запуск

```
pip3 install flask
./run.sh
```

Приложение открывается по адресу http://127.0.0.1:5000

## Структура

```
site/
├── app.py            — контроллеры (маршруты Flask), валидация форм
├── db.py             — слой доступа к данным, SQL-запросы
├── schema.sql        — DDL-сценарий создания базы данных
├── seed.py           — наполнение базы демонстрационными данными
├── templates/        — шаблоны Jinja2 (представления)
└── static/
    ├── css/style.css — таблица стилей
    └── js/app.js     — клиентские сценарии
```
