# Аудит доступности (WCAG 2.2 AA, ГОСТ Р 52872-2019)

Учебная практика УП.09.02, тема 1. Объект аудита — веб-приложение «Афиша мероприятий».

| Папка | Содержимое |
|---|---|
| `results/before/` | результаты до исправлений: `audit.json` (axe-core + ручные проверки), отчёты Lighthouse `lh-*.report.html` |
| `results/after/` | те же проверки после исправлений |
| `tools/audit.mjs` | скрипт: axe-core на 9 страницах (в т.ч. под ролями пользователя и администратора), обход Tab, масштаб 200 %, заголовки, `lang` |

## Повторить проверку

```bash
# 1. запустить сайт
AFISHA_PORT=5051 python3 app.py

# 2. в другом окне
cd a11y-audit/tools
npm install
node audit.mjs after http://127.0.0.1:5051
npx lighthouse http://127.0.0.1:5051/ --only-categories=accessibility --locale=ru
```

Нужен установленный Google Chrome (путь к нему указан в `audit.mjs`).
